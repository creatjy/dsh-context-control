# dsh-context-control UI 设计说明

| 项目 | 内容 |
| --- | --- |
| 适用版本 | 0.6.7 |
| 对应实现 | `client.js`（Panel / ComposerChip / ChipPopover / CSS） |
| 设计目标 | 让「这一轮发了多少、下一轮还要多发多少、哪些能不发」在一层浮窗里可读、可改、可撤销 |
| 主题 | 跟随 DSH 的 `--dsw-alias-*` 变量，亮/暗色自动适配 |

这份文档描述**当前实现**的界面结构、尺寸、状态与交互，不重复需求文档里的压缩流水线与服务端规则。需求与技术方案见 [`需求与技术方案.md`](./需求与技术方案.md)。

---

## 1. 设计目标

1. **两秒内回答三个数**：当前窗口、每次重发、下一轮预计。三个数必须在同一视觉层级，不能让人做加法。
2. **配置与试用分离**：左侧面板改的是项目/全局的长期规则；胶囊浮窗改的是本会话的临时覆盖。两者视觉同源，但作用域文案必须明确。
3. **骨架稳定**：切页签、刷新数据、长列表滚动时，浮层高度、页签行、页头行、工具栏都不跳动。
4. **状态可解释**：加载中、空、筛选无结果、所属能力被关闭、压缩排队、压缩失败，都要有就地文案，不用猜。
5. **不打断对话**：胶囊浮窗是非模态的，没有遮罩，不抢焦点；点浮层外或按 `Esc` 就回去。

## 3. 设计原则

- **先总量，后明细**：概览先给三个数，再给两组可勾选明细；不在首屏铺 100 多行。
- **同层同构**：五个内容页共用同一条 30px 页头、同一条工具栏、同一个滚动内容区；页签只换标题、meta 和右侧动作。
- **作用域可见**：会话层的项都带「本会话」标签；页头写「继承项目 X」，当前层与继承层一眼能分开。
- **颜色只做辅助**：加载/简介/隐藏三档既有颜色，也有文字；关闭项除置灰外还有删除线/标签，不依赖颜色单独传达。
- **紧凑但不挤**：正文 11.5–12px、行高 1.5，靠间距和分组建立层级，而不是靠大字号。

## 5. 组件规格

### 5.1 输入框胶囊 `ComposerChip`

| 项 | 值 |
| --- | --- |
| 高度 | 内容 + `padding:5px 9px`，约 24px |
| 圆角 | 99 |
| 字号 | 11.5 |
| 图标 | 14px，透明度 .75 |
| 箭头 | 9px，透明度 .5 |
| 默认文案 | `上下文 68k ▾` |
| 无数据 | `上下文 ▾` |
| 打开态 | 背景 `--cc-hover`，文字 `--cc-ink` |

- `aria-haspopup="dialog"`，`aria-expanded` 跟随浮层；`aria-label` 带当前总量。
- 打开时拉一次数据；之后每 12 秒刷新；`focus`、`visibilitychange`、关闭浮层时各补一次。
- 胶囊不占输入框宽度：它是 `conversation.input.left` 的一个 inline 按钮，不展开时不显示任何面板。

### 5.2 浮窗外壳 `ChipPopover`

| 项 | 规则 |
| --- | --- |
| 定位 | `position:fixed`，底边贴在胶囊上方 10px |
| 宽度 | `min(490px, 100vw - 24px)` |
| 左右安全边 | 至少 12px |
| 最大高度 | `max(240, min(560, 视口底部到输入框上方 - 16))` |
| 固定高度 | 首次在「概览」测量自然高度；`max(测量值, min(maxHeight, 520))` |
| 圆角/边框 | 12px / 1px `--cc-line` |
| 层级 | `z-index:70`，无遮罩 |
| 关闭 | 点浮层外 `mousedown`；`Esc`；右上「关闭」 |

浮层内部是纵向 flex，顺序固定：

1. `.cc-pop-head`（页头）
2. `.cc-ptabs`（页签行，38px）
3. `.cc-pop-page-head`（30px，仅非概览）
4. `.cc-pop-toolbar`（仅非概览）
5. `.cc-pop-body`（`flex:1 1 0`，独立滚动）
6. `.cc-pop-foot`（仅概览）

高度固定后，切到技能/MCP/插件/提示段/工具只换内容，不改变外框高度。

### 5.3 浮层页头 `.cc-pop-head`

```text
≈68k   窗口占用 · 共 128k                    刷新   关闭
```

- 左：总占用 `≈68k` + 说明；无数据时「本会话上下文 / 还没读到计量」。
- 右：`刷新`（loading 时显示 `…`）、`关闭`，都是 ghost mini 按钮。
- 下边框 `--cc-soft`，padding `10px 12px 8px`。

### 5.4 页签行 `.cc-ptabs`

- 六个页签固定顺序：`概览 / 技能 / MCP / 插件 / 提示段 / 工具`。
- 高度固定 38px，单行不换行；超宽时横向滚动，滚动条 4px。
- 字号 12 / 600；选中态只加下划线（2px `--cc-on`）和颜色，不加粗。
- badge 10px / 行高 15px；概览显示条目数，技能/MCP/插件显示条目数，提示段/工具显示「生效/总数」。
- 页签切换只改 `tab`，筛选词保留。

### 5.5 共享页头 `.cc-pop-page-head`

概览不显示这一行；其余五页共用，固定 30px：

```text
技能        本会话 · 继承项目 dsh-context-control · 16/16 已加载
```

- 左侧页名：固定 `flex:0 0 46px`，保证五页文字同列。
- 中间 meta：11px，单行省略，`title` 保留全文。
- 右侧不在页头放动作；动作全部收进工具栏，避免切页时首行高度变化。

### 5.6 共享工具栏 `.cc-pop-toolbar`

```text
[ 筛选技能、MCP、插件、提示段、工具…    × ]  [全部状态▾]   全开  全关
```

- 只在非概览页显示，padding `6px 12px`，下边框。
- 左：搜索框，`flex:1 1 auto; min-width:0`；有值时右侧出现 20px 圆形 `×`。
- 中：`select.cc-status-select`（全部状态 / 已开启 / 已关闭），`flex:0 0 auto`；宽度约 78px，28px 高。
- 右：`.cc-cap-actions`，仅技能/MCP/插件页显示「全开 / 全关」；提示段/工具页没有按钮。
- 筛选作用于当前页列表；状态筛选与文本搜索叠加；全开/全关作用于整组，不受两者影响。浮层切页时状态保留；面板切换子页时重置。
- `Esc` 在筛选输入框里只清筛选并阻止冒泡（不会关闭浮层）；要点 `×`、`关闭` 或点浮层外来关闭。

### 5.7 内容区与页脚

- 内容区：`flex:1 1 0; min-height:0; overflow-y:auto`，padding `9px 12px 10px`；概览 `padding-top:4px`。
- 页脚只在概览出现：`padding:8px 12px`，上边框，左侧说明单行省略，右侧按钮不换行。
- 页脚左侧文案：
  - 未勾选且可压缩：「立即压缩不用勾选，宿主自己挑区间」
  - 未勾选且降级：「本 profile 走 steer 指令：不勾就用默认四块，勾了就只压这些」
  - 已勾选：「已勾选 N 块 · ≈X（只影响「写入输入框」）」

### 5.8 基础控件

| 控件 | 规格 |
| --- | --- |
| 主按钮 `.cc-btn.is-primary` | 背景 `--cc-ink`（近黑），白字，圆角 7，高约 26 |
| 次按钮 `.cc-btn` | 边框 `--cc-line`，背景透明 |
| Ghost mini `.cc-btn.is-ghost.is-mini` | 无边框，11px，用于刷新/关闭/全开全关 |
| 三档分段 `.cc-seg` | 胶囊底 `--cc-soft`；选中白底 + 1px 描边 + 600；加载蓝、简介黄、隐藏红 |
| 开关 `.cc-switch` | 30×18，圆点 14；开启 `--cc-on`；关闭灰；禁用 0.45 透明 |
| 标签 `.cc-tag` | 圆角 4、背景 `--cc-soft`、10.5px；「本会话」用中性色，能力态用对应色 |
| 数字 `.cc-num` | 右对齐、`tabular-nums`、11.5px |
| 输入 `.cc-input` | 高 28、圆角 7、1px 边框；聚焦时 `--cc-on` 边框 + 3px 光晕 |

## 6. 页面规格

### 6.1 概览

概览没有 30px 页头，也没有工具栏；内容区顶部只有汇总条。

```text
[ⓘ] 当前窗口 68.0k    每次重发 ≈ 42.1k    下一轮预计 ≈ 110.1k
────────────────────────────────────────────────────────────
会话已累积                          N 项 · ≈68.0k
  ☑ 用户消息                        6 项   ≈3.8k
  ☑ 助手消息                       84 项  ≈32.5k
  ...
每次请求都会重发                     N 项 · ≈42.1k
  按文本估算，其中工具定义占大头；已按隐藏项扣减。
  ☐ 系统提示段                      ...
────────────────────────────────────────────────────────────
额外要求（可选） [例如：只保留结论与文件路径，不要日志全文]
```

- **汇总条**：底色 `--cc-hover`，1px 边框，圆角 8；三个数用 `<b>` 加粗；「当前窗口」前是 13px 圆形 `i`。
- **ⓘ**：鼠标 `pointerenter` 展开、`pointerleave` 收起；触摸点击展开；点浮层外或 `Esc` 收起。`aria-expanded` 跟随。
- **分组**：`会话已累积`、`每次请求都会重发`；组头显示「N 项 · ≈X」，下面一行 hint。
- **行**：checkbox + 名称 + 可选「N 项」+ 右对齐 token；行高约 25px；选中名称加 600。
- **额外要求**：单行输入，placeholder 是示例，不占多行。
- **自动压缩设置**：汇总/明细之后显示勾选框 + 数字输入（5–95）；输入越界时失焦后显示 5 或 95。
- **页脚**：只在概览出现；`写入输入框`（次按钮）+ `立即压缩`（主按钮，不可用时变「发送压缩指令」）。

### 6.2 技能 / MCP / 插件

```text
技能        本会话 · 继承项目 dsh-context-control · 15/16 已加载 · 少发 ≈45
[ 筛选…                                × ]  [全部状态▾]  全开  全关
────────────────────────────────────────────────────────────
plugin-test  [本会话]                          ≈1.2k  [加载|简介|隐藏]
plugin-upgrade                                ≈8.9k  [加载|简介|隐藏]
agent-team-portable                           ≈123   [加载|简介|隐藏]
```

- 页头 meta 的 `n/N` 是**已加载**数量（`mode === "on"`），不是条目总数；后面的「少发 ≈Y」按非加载档位的 token 估算，0 也显示。
- 行：名称（可省略，title 给全名）+ token + 三档分段；有会话覆盖时名称旁标「本会话」。
- 行末不再放「继承 / 还原 / ↺」按钮；要回退直接重新点三档即可。
- 切换一个能力档位时，它关联的提示段与工具会同步写入同层规则；手动编辑过关联规则后，后续联动只撤销自动标记，不覆盖手写文本。
- 能力当前为「简介 / 隐藏」时，行名与 token 按档位弱化；三档仍可点，写入的是本会话覆盖，页头计数与少发即时更新。
- 0.6.2 起没有 `toolbox:catalog` 段时，技能来自磁盘目录：同样显示「加载 / 简介 / 隐藏」三档，可保存本会话档位；token 按目录行估算并显示，安装/启用懒工具箱后档位生效。
- 底部 note：「只作用于本会话，不改项目/工作区；加载 = 正文与工具都发，简介 = 只留一行说明，隐藏 = 连简介都不发，调用要审批。」

### 6.3 提示段 / 工具

```text
提示段      本会话 · 继承项目 dsh-context-control · 22/26 生效 · 少发 ≈3.2k
[ 筛选…                                × ]  [全部状态▾]
────────────────────────────────────────────────────────────
[开关] free-search:engines     搜索工具说明…    ≈420   [简介]
[开关] mcp:github              46 个工具…      ≈14.4k  [本会话]
```

- 页头 meta 的 `n/N` 是**实际发不发**：`enabled && 所属能力为 on` 才算生效；隐藏项计入「少发」。
- 行：开关 + 名称（code 样式）+ 能力标签（简介/隐藏）+「本会话」+ 预览 + token。
- 所属能力被关掉时整行 `is-off`，开关禁用，title 说明「所属能力 X 被关闭，先在上面的能力页打开」。
- 关闭项名称加删除线，预览透明度 .6；token 显示 0。
- 底部 note：「只作用于本会话，不改项目/工作区；这里只做开关，正文改写请到左侧项目页的「系统提示」/「系统工具」。」

### 6.4 左栏面板

面板是独立页面，不是浮层：

```text
上下文管控                                   本次请求 ≈42.1k   刷新
[========= 系统内容 =========][== 运行时 ==][==== 工具定义 ====]
构成    项目    全局
────────────────────────────────────────────────────────────
系统提示  运行时注入  工具定义
...
```

- **顶部仪表条**：`position:sticky; top:0`，padding `14px 26px 0`，毛玻璃背景；标题 14，右侧总量 15。
- **三段比例尺**：高 6px，圆角 99；tooltip 说明各段 token。
- **页签**：`构成 / 项目 / 全局`，gap 18，padding `0 26px`；下划线选中。
- **内容区**：`max-width:1120px`，padding `6px 26px 40px`。
- **构成**：按系统内容/运行时注入/工具定义分组；组内可展开，逐项开关、编辑、还原；顶部有「一键精简」。
- **项目**：工作目录选择、继承链、能力/段/工具规则、状态账、一键切换。
- **全局**：与项目同构，改一次对所有项目生效；有「全部隐藏」。
- **窄屏 ≤760px**：左右 padding 16；比例尺换行；能力行改两列、工具行改三列；页签可横向滚动。

## 7. 交互规格

| 操作 | 结果 |
| --- | --- |
| 点胶囊 | 打开浮层，默认「概览」，拉取 state；`aria-expanded=true` |
| 点浮层外 / 关闭 / `Esc` | 关闭；焦点在筛选框内时 `Esc` 只清筛选，不关闭 |
| 切页签 | 只换内容；筛选词与状态保留；页头/工具栏按页显隐；外框高度不变 |
| 输入筛选 | 当前页即时过滤；技能/MCP/插件匹配 id/key/summary，提示段/工具匹配 name/preview |
| 选择状态 | 「全部状态 / 已开启 / 已关闭」；能力按当前档位、段/工具按实际生效；与文本搜索叠加；浮层切页保留，面板切子页重置 |
| 点 `×` | 清空筛选 |
| 点「全开/全关」 | 对当前能力组全部条目 `setCap`；不受筛选影响；busy 时禁用 |
| 点三档 / 全开全关 | 写当前层覆盖；同一能力的关联提示段与工具同步开关（`auto` 规则）；立即刷新行状态与页头计数；磁盘技能也保存档位，安装工具箱后生效 |
| 拨段/工具开关 | 写本会话 `setSessionRule`；行 token 与页头「生效/少发」同步 |
| 改「自动压缩」 | 勾选/输入后 `setAutoCompact`；数字 5–95，越界回边界 |
| 点「写入输入框」 | 生成压缩指令写入草稿，不发送 |
| 点「立即压缩」 | 调宿主压缩；忙时排队；结果显示在概览 |
| 刷新 | 重新拉 state 与 session；按钮显示 `…` |
| 打开浮层 | 清空筛选词与状态筛选；默认回到概览 |

反馈状态：

- **加载中**：刷新按钮 `…`；内容区显示「正在读取模块…」。
- **空**：技能/MCP/插件「这一类还没有可配置的条目。」；技能另有「没有检测到技能目录段，也没有在磁盘技能目录里找到技能。安装或启用懒工具箱后，这里会变成可调列表。」；提示段「还没有可读的系统提示段。」；工具「工具表还没读出来。」。
- **筛选无结果**：能力页「没有匹配的条目。」；段/工具「没有匹配的内容。」。
- **错误**：内容区顶部 `.cc-alert` 显示真实错误；成功/完成用 `.cc-alert.is-ok`。
- **压缩排队**：概览「已排队：这一轮结束后自动压缩（现在窗口 X%）。」
- **压缩失败**：显示真实原因，不显示「忙」这类包装文案。

## 8. 响应式与溢出

- **浮层宽度**：`min(490, vw - 24)`；左右至少 12px；输入框贴底时向上弹。
- **浮层高度**：`maxHeight` 由视口上方空间决定（240–560）；目标最小 520，空间不足时以 `maxHeight` 为准。
- **页签**：永远单行，`overflow-x:auto`；不换行、不压缩、不隐藏；滚动条 4px。
- **工具栏**：`flex-wrap:nowrap`；搜索框 `min-width:0` 收缩，按钮 `flex:0 0 auto` 不缩。
- **页头**：页名固定 46px，meta 单行省略；不换行。
- **列表**：名称/预览单行省略；长 token 数字右对齐；内容区独立滚动。
- **页脚**：说明单行省略，按钮组不换行。
- **面板**：≤760px 时改单列/两列，隐藏非关键列（如 bucket count），页签横向滚动。

## 9. 无障碍

- 浮层 `role="dialog"`、`aria-modal="false"`、`aria-label="本会话上下文"`；非模态，不锁焦点。
- 页签 `role="tab"`、`aria-selected`；页签容器 `role="tablist"`。
- 胶囊 `aria-haspopup="dialog"`、`aria-expanded`；按钮都有可读名称。
- `ⓘ` 有 `aria-label="说明"`、`aria-expanded`；提示层 `role="tooltip"`。
- 所有可聚焦元素有 `:focus-visible` 2px 外描边（`--cc-on` 70%）。
- 颜色不是唯一信息：三档有文字，关闭项有删除线/标签，能力关闭有「简介/隐藏」标签。
- 动效遵循 `prefers-reduced-motion`；浮层打开动画可关闭。
- 触摸：`ⓘ` 可点击展开；`Esc` 在移动端无键盘时由点外关闭兜底。

## 10. 设计决策

| 决策 | 原因 |
| --- | --- |
| 胶囊浮窗非模态、无遮罩 | 用户要一边看对话一边改上下文；模态会打断 |
| 会话层开关放浮窗，正文编辑留面板 | 临时试错不该写进项目；正文编辑是长期配置 |
| 六个页签共用 30px 页头与 46px 页名列 | 0.5.18 前各页标题结构不同，切页首行跳动；固定列宽让五页文字同列 |
| 页签行固定 38px、不参与 flex 收缩 | 0.5.20 前工具页 147 条会把页签行挤到几乎不可见 |
| 工具栏固定在页头下，筛选在左、按钮在右 | 0.5.26 前筛选与全开/全关分两行；统一后满足「筛选在按钮前」且只有一条 |
| 筛选框增加状态下拉 | 列表项多时只用文本找「已关闭」很慢；状态与文本叠加比做两套筛选框更省空间 |
| 全局筛选跨五页保留 | 用户常在技能页找完再去工具页找同一个词；每页一个筛选框会重复且丢状态 |
| 概览去掉页头、口径说明收进 ⓘ | 0.5.22/0.5.23 为省垂直空间；口径是解释性信息，不需要常驻 |
| 浮层高度固定、目标最小 520 | 0.5.17 前切到 MCP 列表短、浮层骤缩；0.5.21 用户反馈内容区过短，抬高下限 |
| 页签选中不加粗 | 加粗会改变文字宽度，切换时整行位移 |
| 数字统一 `tabular-nums` | 刷新时数字宽度不跳 |

## 14. AI 建议界面（规划）

AI 建议已实现（0.6.0 起）；0.6.2 把入口收敛为「构成 / 项目 / 全局」三个列表页各一个、胶囊刷新旁一个，明细行不再单独放 AI。以下「行内建议 / 胶囊 sheet」段落保留为早期规划记录，当前实现以本文件第 6、7 节为准。

- 入口统一 `AI 建议 · <层>`，不用「最低可用建议 / 优化本项目 / 分析本页」三套动词；全局页副标题保留「最低可用」；
- 页面级 AI 条默认收起为 22px ghost 按钮，点击展开 37px；`应用选中` 只在结果卡出现一次；
- 全局页：行内建议 pill（未生效为虚线 + `建议隐藏` / `建议简介` / `建议改写`；keep 不显示 pill）+ 结果摘要 + `只看建议`；
- 项目页：只写当前项目层，继承项标 `继承`；构成页：只写当前模式，可编辑行有 `AI 改写` diff + `只看可改写`；
- 胶囊：页头 24×24 `AI` 按钮打开会话 sheet，只写会话层；sheet 只有一个「返回」，打开时隐藏页签；
- 所有建议带 reason/confidence/risk/savedTokens，风险/置信显示中文；默认只勾选低风险且非低置信，先预览再应用，可撤销；
- 0.6.6 起建议行保持紧凑单行；鼠标悬停、点击或键盘聚焦整行时，用 fixed 定位气泡展示完整名称、档位、少发与理由；点气泡外、按 Esc 或滚动时收起；
- 跨插件/工具影响分析默认关闭：结果卡头部右侧 `AiImpactToggle` 默认「仅分析本层」，勾选「含其他插件/工具影响」后多一次模型调用；切换只标 stale，不自动重跑；影响以 11px sub-line 挂在建议下，阻断项默认不勾选、不进批量。

完整规格与示意图见 [AI建议-UI设计.md](./AI建议-UI设计.md)；后端契约（含 impactScan 与 impacts 契约）见 [AI建议-架构方案.md](./AI建议-架构方案.md)。
